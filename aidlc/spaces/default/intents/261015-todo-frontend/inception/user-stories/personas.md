## Persona 1: Casey, the everyday task keeper (primary and only persona) [Q1]

| Field | Value |
|-------|-------|
| Name | Casey |
| Role | A member of the general public who keeps a personal to-do list in the browser |
| Goals | Note a task the moment it comes to mind; see at a glance what is still to do; tick things off |
| Pain points | Forgets tasks that are not written down; finds heavy tools with accounts and settings slow for a simple list |
| Tech comfort | Medium |
| Frequency | Several times a day |
| Context | Current desktop browser (Chrome, Edge, Firefox or Safari); no account; one browser on one machine |

Casey is the whole audience named in the intent ("the general public"), so every story is written for Casey.

## Persona relationships and priority

- Only one persona, so no relationships and no ranking are needed.
- Needs that apply to every person but would only need a separate persona if they changed a story (keyboard-only use, return visits) are written into Casey's stories as acceptance criteria instead: keyboard use appears in US1.1 to US5.1 and returning to saved tasks in US6.1.

## Assumptions & Open Questions
