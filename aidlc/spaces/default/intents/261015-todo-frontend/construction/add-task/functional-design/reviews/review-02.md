> R-01 Reviewer note: The notice state machine now has a row for every pair of current notice and event. It agrees with W4, BR1.12 and contract C4: a failed save always shows `save-failed`, and a good save returns to `load-failed` only when the load had failed.

> R-02 Reviewer note: BR1.11 makes `load` check version, five-field shape and title rules, using the same check `save` applies. The U1/U6 split is stated, and the open question asks the owner to update `unit-of-work.md`.

> R-04 Reviewer note: "Changes to earlier documents" now lists the C5 `message` deviation, C3 (`checkTitle` kept, `save` and `load` changes), the C2 wording and its first-save open question, the C4 notice shape, FR6.3, M9, ADR-006 and `docs/ARCHITECTURE.md`.
